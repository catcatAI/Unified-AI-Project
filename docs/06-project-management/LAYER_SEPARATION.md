## 一句話規則

**能力由什麼承載，就屬於哪一層——不是由它「看起來」多聰明決定。**

## 五層

| 層                 | 承載物                                   | 可以回答                   | 必須有                                                | 絕不可當作        |
| ------------------ | ---------------------------------------- | -------------------------- | ----------------------------------------------------- | ----------------- |
| **記憶 memory**    | 一筆可歸屬、可撤銷的紀錄（誰說的、何時） | 「你剛才說…」「你教過我…」 | 出處（使用者/文件）、可更正、語氣上歸屬（不一概斷言） | 知識、學習、智能  |
| **知識 knowledge** | 有公開/策展來源的命題                    | 「根據 X，Y 是 Z」         | 來源、可重現的檢索                                    | 學習              |
| **思考 reasoning** | 由輸入推導出的結果                       | 算式、邏輯、證明           | 可重現的推導步驟（不是查表）                          | 記憶              |
| **學習 learning**  | **參數**（權重/表徵）裡的改變            | 來源刪除後仍答得出來       | 探針**刪除來源後**仍通過                              | —（本身就是學習） |
| **表層 surface**   | 路由、模板、措辭                         | 「送去哪裡」「怎麼說」     | 只是 I/O                                              | 知識、學習、智能  |

### 判位測驗（依序問，第一個成立的就是答案）

1. **把來源刪掉（文字、紀錄、對話），還答得出來嗎？**
   是 → 學習；否 → 記憶/檢索（不管它當場多流暢）。
2. **這個回答是「某個人說過的紀錄」嗎？**
   是 → 記憶：可過期、可錯、必須標示來源。
3. **這是「與誰問無關、有來源的命題」嗎？** 是 → 知識：要出處，不能由表層編造。
4. **這是「從輸入推導、可重現」的嗎？** 是 → 思考：不能是存起來的字串。
5. **它只決定去處或說法嗎？** 是 → 表層：不得成為 1–4 的來源。

## 兩個結構性防線（不是靠自律）

1. **記憶不進知識路徑**：`route_knowledge()` 不得 import
   `ai.memory`（AST 檢查），對話教學只在聊天管線回應，且標
   `source=memory`、文字帶「你教過我」。好處：benchmark 的 `knowledge`
   維度永遠不可能被對話記憶餵高。
2. **學習宣稱必須有刪除來源的證據**：`evidence.source_deleted` 必須是
   `true`，且探針要真的重建「只留參數」的狀態再問一次。沒有這一步的探針，測的是儲存。

## 反模式（看到就退件）

- 「答對了」＝「學會了」：沒有刪除來源的探針。
- 「換句話問也對」＝「泛化」：先教了同義詞、再用字串/子詞比對。
- 「探針沒改程式碼」＝「沒作弊」：機制本身是兩次跑之間新增的碼。
- 「模板／路由很準」＝「知識／智能」：那只證明派工與措辭。
- 「記憶查得到」＝「知道」：記憶可錯、可過期，且必須標示誰說的。

## 新增一條宣稱時

1. 先回答判位測驗，決定層。
2. 在實作模組標頭寫 `# LAYER: <layer>`。
3. 在 `LAYER_REGISTRY.json`
   增一筆（實作、探針、方法、結果、`must_not_be_used_as`）。
4. 跑 `./.venv/bin/python scripts/check_layer_separation.py`； `learning`
   的探針必須包含「刪除來源後再問」。
5. 文件只引用登記簿的數字，不另寫一套。
