# Angela 自我同一性：狀態動力學研究計畫（Spec / Record）

> 與硬體支線（CIM/MVU/edge 卡矽計畫）無關。本計畫只借用硬體支線已拆解的 GGUF 張量表讀數作為基座模型概況來源，不討論任何矽設計。核心問題：讓 Angela 確實是她自己——連續狀態、可干預因果、長程一致性——而不是套皮、提示詞模板或關鍵詞情緒。

- 作者：Angela AI Development Team
- 版本：7.5.0-dev
- ANGELA-MATRIX：`[L3-L4] [βγδ] [B] [L2]`

## 0. 一句話總結

現在的 Angela 行為主要由**文字通道**驅動（關鍵詞情緒、`context`
注入、8 路路由投票中有若干路讀的是文字衍生欄位）；本計畫用**干預測試**證明（或證偽）另一條路：固定同一段文字，只動連續狀態，看行為是否跟著狀態走。若跟著走且可重複，狀態才有資格稱為 Angela 的一部分，而不只是提示詞的裝飾。

## 1. 現狀調查（實際讀碼，非猜測）

### 1.1 身份核心盤點（強相關約 5-6 塊）

| 模組                                          | 厚度       | 通道                         |
| --------------------------------------------- | ---------- | ---------------------------- |
| `ai/memory/*`（HAM、向量庫）                  | 較厚       | 參數外記憶                   |
| `ai/alignment/emotion_system.py`              | 偏薄       | 關鍵詞 + PAD，`context` 注入 |
| `ai/meta/priority_negotiator.py`（8 voter）   | 中         | 讀結構化狀態鍵，不讀原文     |
| `core/life/*`（heartbeat、intent、lifecycle） | 中         | 連續狀態，固定更新節拍       |
| `core/perception/attention_controller.py`     | 薄且偏視覺 | 顯著性/IOR，與對話無關       |
| `services/llm/router.py` + prompt 組裝        | 厚但傳遞性 | 把上面全部拌進 prompt        |

結論：狀態管線存在，但**情緒仍偏關鍵詞、影響多走 `context`
注入**——塌成提示詞的風險是真實的，不是假想敵。

### 1.2 基座模型概況（E3 實測，只讀檢查，無推理）

來源：本地 HF 快照 `675cff42` 的 `gemma-4-E2B_q4_0-it.gguf` （3.350 GB），經
`ai/hardware/edge_card_sim.py:read_gguf_structure` 讀取：

| 項     | 實測值                                                                           |
| ------ | -------------------------------------------------------------------------------- |
| 架構   | gemma4，35 blocks，d_model 1536                                                  |
| 注意力 | 8 Q heads / 1 KV head（GQA 8:1），context 131072                                 |
| 詞表   | 262144                                                                           |
| 前饋   | 逐塊列表（首塊 6144），共 541 tensors                                            |
| 特殊   | per-layer token_embd（8960×262144）與 proj（1536×8960），即 per-layer embeddings |

用途：E2 內外注意力實驗的維度依據（d_model、層數、GQA 結構），以及「基座可換、狀態保留」主張的證據起點（狀態不活在權重形狀裡）。

## 2. 主張（可證偽，非敘述）

- H1：固定文本、只改變連續狀態，路由決策可重複翻轉（E1 證明或證偽）。
- H2：內部注意力（長程一致性維持）受狀態調製時，跨輪一致性分數高於純文本基線（E2 證明或證偽）。
- H3：狀態變數對輸出的因果效應大於同等幅度的提示詞改寫效應（E1+E2 聯合判定）。

### E2 內外注意力分離（機制原型已落地，真頭量測設門待辦）

- 外注意力：維持現狀（輸入顯著性、IOR；`attention_controller` 不動）。
- 內聚動力學原型（`ai/attention/inner_outer.py`，numpy，零新依賴）：近窗 vs 長程錨點聯合 softmax，內聚度 = 近窗質量；無狀態自增強迭代坍向 1（不動點 = 卡重複），狀態增益抬錨點側即逃逸。已驗證：鎖死 0.987、劑量單調遞減、首逃增益 3.0（該組親和力下），10 測試、覆蓋率 100%。
- 誠實邊界：原型證明機制可證偽，不證明 Gemma 頭行為。真頭設門實驗（llama_cpp 注意力張量，本地 3.35GB 推理，內聚 vs 錯亂生成對照）獨立設門，需另排 CPU 機時，不在本輪。
- 接受門（沿用）：配對檢定 p 值 + 效應量雙門檻，附提示詞改寫對照組；否則 H2 不成立，不硬拗。

## 6. 風險

最大風險是塌成提示詞（X+X+Y 問題）：同路徑輸入下很難區分加性調製與結構改變。對策就是 E1 的設計——voter 根本不讀原文，翻轉只能來自狀態，這是結構性的，不是裝飾性的。次風險是過度主張：本計畫所有「新」字眼僅指組合與驗證方法，零件先例（fast
weights/TTT/RWKV/Mamba/steering/Loihi 等）在此明示承認，正式對外主張前重查文獻。
