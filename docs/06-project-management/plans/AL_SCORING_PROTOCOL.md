# AL 下游評分協定 v2（`al-downstream-v2`）

> **誠實標籤**：這份協定是**事後**訂的，不是預先註冊。§20–§23 已經看到「讀出、剪枝門檻、訓練量」三者都能翻轉結論，所以協定的價值在於**從現在起固定**、讓後續量測不能繼續挑 regime；它不能回溯地把先前那些結果變成預先承諾的檢定。

實作：`scripts/al_downstream_protocol.py`（常數寫死，不從命令列給）。測試：`tests/test_al_downstream_protocol.py`。

## 協定內容

| 項目        | 固定值                                                                 | 理由                                                                            |
| ----------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 讀出        | `potential`（膜電位）                                                  | §20：脈衝次數在同權重下 0.0、膜電位 1.0，排序能力全在讀出                       |
| 任務族      | `hard`：cue token + 噪聲位，全部共用一個 `shared` 位                   | 有干擾，才測得到「學得對不對」                                                  |
| regime 矩陣 | epochs ∈ {1, 5}                                                        | 兩個都跑、**兩個都報**，不允許挑                                                |
| 難度校準    | 固定階梯 `(48,3) (96,3) (96,2) (144,2) (144,1)` × lr 格點 `0.005…0.05` | 取第一個讓**中性臂** top-1 落在 [0.30, 0.70] 的組合；校準不到 → `uninformative` |
| 種子        | 12 個固定（11, 23, 37, 41, 53, 67, 79, 83, 97, 101, 113, 127）         | 校準另用 3 個，與評估分開                                                       |
| 控制組      | `shuffled`：**同一組增益**打亂順序                                     | 分離「平均增益」與「時序」                                                      |
| 主指標      | held-out margin（正確 − 最強對手，膜電位）                             | 連續值，不受脈衝量化影響                                                        |
| 共同指標    | top-1 命中率                                                           | margin 升而 top-1 降**不算贏**                                                  |
| 增益匹配    | 三臂平均增益差 ≤ 0.05，否則 `gain-not-matched`                         | 比較才有意義                                                                    |

## 整體判詞

- `insufficient-informative-regimes`：可下結論的 regime < 2；
- `mechanism-benefit-consistent`：全部可下結論的 regime 都是
  `phase-beats-matched-mean`；
- `no-mechanism-benefit-consistent`：全部都沒贏過 neutral；
- `regime-dependent-no-claim`：方向不一致。

## 協定修訂紀錄

**v1 → v2**：v1 只校準 lr（任務固定 48/3）。結果 ep5 在**任何**
lr 都停在 0.979（lr
0.005–0.05 全同）——5 輪訓練下這個場景結構上太容易，lr 不是瓶頸。所以 v2 把「難度」也變成可校準維度，並用固定階梯（不是逐格硬調），同時把校準不到的 regime 明確標成
`uninformative` 而不是硬跑。

## v2 執行結果（2026-11-07）

| regime   | 校準                                  | neutral          | phase                | shuffled         | 判詞                       |
| -------- | ------------------------------------- | ---------------- | -------------------- | ---------------- | -------------------------- |
| epochs 1 | 48 候選 / 3 位、lr 0.03（中性 0.507） | +0.02431 / 0.502 | **−0.03378** / 0.481 | −0.03308 / 0.483 | `no-downstream-difference` |
| epochs 5 | 96 候選 / 2 位、lr 0.03（中性 0.465） | +0.01020 / 0.443 | **+0.34545 / 1.000** | +0.05706 / 0.668 | `phase-beats-matched-mean` |

**整體判詞：`regime-dependent-no-claim`。**

兩個可下結論的 regime 方向相反，而且都不是雜訊等級的差距：

- 一次性學習（1 epoch）：相位調制**有害**，margin 由正翻負；
- 五輪學習（5 epochs）：相位調制**大幅有益**（top-1 0.443 →
  1.000），而且贏過同增益打亂的 0.668——這是目前唯一一次「時序本身有貢獻」的量測。

## 因此能說與不能說

**能說**：在這支 LIF 模型上，調制的效果**取決於訓練體制**；任何單一 regime 的結果都不足以回答「機制有沒有用」。協定把這件事固定下來，並要求兩個 regime 一起報。

**不能說**：

- 不能說「相位調制有效」（ep1 反例）；
- 不能說「相位調制無效」（ep5 反例）；
- 不能說「時序沒有意義」（ep5 的 phase 0.345 > shuffled 0.057）；
- 也不能把 ep5 的結果推廣到別的任務、別的超參數或別的模型。

## 下一步（協定之內）

要讓結論從 `regime-dependent` 走向可宣告，需要的是**第三個 regime**（例如 epochs
3 或 10）與**第二個任務族**（不同干擾結構），而不是再調整現有兩格。若多個 regime 與多個任務族方向一致，才構成可宣告的機制結論；否則就維持「條件相依」。

## 協定修訂紀錄（續）

**v2 → v3**：v2 只有兩個 regime、一個任務族，結論 `regime-dependent-no-claim`
但無法區分「regime 本身」與「任務族」。v3 的做法是**增加獨立維度**，不是再調參數：

- regime 矩陣擴成 epochs ∈ {1, 3, 5}；
- 任務族擴成兩個：`hard`（全體共用噪聲位）與
  `many_to_one`（兩個 cue 共用同一個 target，干擾真的存在但答案仍可學）；
- 每個（任務族 × regime）各自沿固定階梯校準到中性臂 top-1 ∈ [0.30, 0.70]。

中途試過兩個結構但被否決，理由也留在這裡：區塊干擾（`block`）在 ep3/ep5 全部飽和到 1.000；重疊 cue（`overlap`）因為每 cue 仍有專屬 token，一律 1.000。兩者都不是「更難」，只是「更吵」。

## v3 執行結果（2026-11-07）

六格全部校準成功（沒有 `uninformative`）：

| 任務族      | regime | neutral          | phase                | shuffled         | 判詞                       |
| ----------- | ------ | ---------------- | -------------------- | ---------------- | -------------------------- |
| hard        | ep1    | +0.02431 / 0.502 | −0.03378 / 0.481     | −0.03308 / 0.483 | `no-downstream-difference` |
| hard        | ep3    | −0.01458 / 0.443 | **+0.21722 / 1.000** | −0.01671 / 0.500 | `phase-beats-matched-mean` |
| hard        | ep5    | +0.01020 / 0.443 | **+0.34545 / 1.000** | +0.05706 / 0.668 | `phase-beats-matched-mean` |
| many_to_one | ep1    | +0.01814 / 0.486 | −0.07006 / 0.142     | −0.07942 / 0.123 | `no-downstream-difference` |
| many_to_one | ep3    | +0.00708 / 0.479 | **+0.01112 / 0.479** | +0.00572 / 0.424 | `phase-beats-matched-mean` |
| many_to_one | ep5    | +0.01492 / 0.479 | **+0.02316 / 0.479** | +0.01394 / 0.477 | `phase-beats-matched-mean` |

**整體判詞仍是
`regime-dependent-no-claim`**（規則要求全部同向才算宣告），但這次模式不再混亂：方向**單調取決於訓練量**，且**兩個任務族一致**——

- **1 epoch：調制有害**（hard −0.034 vs +0.024；many_to_one top-1 0.142 vs
  0.486，差很大）；
- **3、5 epochs：調制有益**（hard top-1 0.443 →
  1.000；many_to_one 同為 0.479 但 margin 較高）。

`phase` 勝過 `shuffled` 的幅度則不穩定：hard ep3/ep5 很大（0.217 vs
−0.017、0.345 vs 0.057），many_to_one 只有 0.011 vs 0.006、0.023 vs
0.014——**時序的貢獻在小干擾場景裡很薄**。

## 現在能說的一句話

在這支 LIF 模型上，**調制的效果正負由「基線訓練到什麼程度」決定**：基線還沒學會時，調制讓它學更慢、更差；基線學會之後，調制讓它學得更準（hard 族 top-1
0.443 → 1.000）。任務族的干擾結構不改變這個方向，只改變幅度。

## 仍然不能說

- 不能說「相位調制有效」——ep1 兩族都是反例；
- 不能把 ep3/ep5 的幅度當成普遍效果——many_to_one 的 margin 差距只有 hard 的 1/20；
- 不能說機制在別的模型或真實語料上也如此——這裡全是合成關聯任務。
