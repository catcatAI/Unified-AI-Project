# 遊戲總覽 (Game Overview)

## 附屬遊戲：角色扮演模擬 (Ancillary Game: Role-Playing Simulation)

### 遊戲是什麼

本專案的附屬遊戲是一個**CLI 命令列角色扮演模擬**，目標運行環境為終端機，絕對不包含圖形化 UI。使用者透過文字指令與遊戲世界互動。

核心特色為**模擬**而非純粹冒險：NPC 有自己的生活圈與作息，主線與支線任務並存，角色之間存在關係與社交系統，玩家可選擇現有 NPC 作為自己的角色，也可在新建角色卡後進行模擬。

### 遊戲不該是什麼

| 不該是 | 而是 |
|--------|------|
| 圖形化 UI 遊戲 | CLI 純文字終端遊戲 |
| 只有冒險沒有模擬 | 角色扮演 + 生活模擬 + 冒險 |
| NPC 是靜態腳色 | NPC 有獨立作息、行程與生活圈 |
| 角色立繪是圖片 | 角色立繪是符號組成的文字藝術 |
| 只有單一角色 | PC / NPC / GM 三種角色類型 |
| 沒有裝備系統 | 全身 12 欄位裝備，含屬性乘區與耐久 |
| 只背包物品 | 物品有屬性乘區、耐久、合成等完整系統 |
| 沒有地圖與場景 | 地圖連接場景，場景含不動產與物件 |
| 載具只是裝飾 | 載具是可互動物件，可騎乘/操作 |
| UI 介面 (按鈕/面板) | 終端呈現的符號與文字介面 |

### 角色類型

| 類型 | 說明 | 控制者 |
|------|------|--------|
| **PC (玩家角色)** | 玩家操控的角色，可從 NPC 中選擇或新建角色卡 | 玩家 |
| **NPC (非玩家角色)** | AI 驅動的角色有自己的生活圈與作息 | AI / GM |
| **GM (遊戲主持人)** | Angela AI 負責場景描述、事件觸發、規則裁決 | Angela AI |

### 角色屬性系統（三色條）

🔴 **紅條 (身體)**
- HP (血量) | 身體 (body) | 肢體 (limbs)
- 每個肢體可獨立受損 (頭/軀幹/左上臂/右上臂/左腿/右腿)，肢體健康歸零 = 失去功能

🔵 **藍條 (靈)**
- 靈活躍度 (spirit activity) | 體力 (stamina) | 魔力 (magic)
- 個體靈的清醒程度，決定魔法干涉能力與感應灵敏度

🟢 **綠條 (經歷)**
- 經驗 (EXP) | 級別 (Level) | 技能 (Skills)
- 聲望 (Reputation) | 歷史 (History)

### 裝備欄系統

角色全身上下 12 個裝備欄位：head, face, neck, torso, left_arm, right_arm, left_hand, right_hand, waist, legs, feet, back

每件裝備提供屬性乘區加成，並帶有耐久系統。耐久歸零 = 裝備失效。

### 物品與物品欄

物品可分為以下屬性：
- 屬性乘區（如武器增加力量、耐甲增加體質）
- 耐久（裝備與工具均有耐久值，使用會損耗）
- 合成（物品可透過合成系統進行組合與加工：組合、加工、煉金）
- 堆疊（可疊加物品，如藥水）
- 裝備（可裝備到裝備欄的物品）
- 消耗品（使用後消失）
- 任務物品（鎖定不可丟棄）

物品欄有最大欄位數與最大負重限制。

### 地圖與場景

- 地圖：連接各場景的區域地圖
- 場景：遊戲中的場所，可為室內/室外/迷宮
- 不動產：場景中的建築物，可購買、升級、改建（住宅、商店、工坊、農場、倉庫、塔樓）
- 物件：場景中可互動的物品（容器、工作台、装饰物、載具、機制）
- 載具：可騎乘或操作的載具

### 角色卡與世界觀生成（根據實際卡片堆數據）

| 場景卡 | 24 | 場景定義（S01~S17, SC-01, SC-20~SC-24） |

#### 角色卡是框架模板

- 59 張角色卡是框架模板，不是特定世界中的具體角色
- 每張角色卡有 `tokens` 字段，定义该角色的能力框架（13 種 token 類別）
- 提取差異是「有或沒有」：某張卡有「combat」token 就是戰士原型，沒有就是非戰士
- 沒有固定的種族/物種欄位：角色的「種族」由其 token 組合決定
- **vitality** 是最核心的 token，75 張角色卡擁有——這是「勇者原型」的標誌

#### 角色原型分類

| 原型 | 特徵 token | 對應遊戲角色 | 卡片數量 |
|------|-----------|-------------|----------|
| 勇者 (combat + vitality) | 戰鬥+生命力 | 主力戰鬥角色、英雄 | 約 40+ |
| 村民 (vitality only, 無 combat) | 僅生命力 | 日常NPC、村民、商販 | 部分 |
| 工匠/製作者 (craft + relation) | 製作+社交 | 工坊主人、商人 | 約 8+ |
| 學者/知識者 (knowledge + lore) | 知識+學識 | 圖書館員、教師 | 約 6+ |
| 特殊能力者 (element + energy) | 元素+能量 | 術士、魔法使用者 | 約 5+ |
| 社交者 (social + relation) | 社交+關係 | 使者、間諧者 | 約 4+ |

#### 場景卡概覽（24 張）

場景卡定義了遊戲中的場景：方碑丘校園（8場景）、中央大圖書館、鏡湖、西翼大市集、海峽、迴廊深層夢境，及幾個 SC 前綴的特殊場景（英雄堡銀行區、珊瑚台、黑淵台、彩紋礁、流光）。所有場景均為框架模板，可動態生成到隱藏世界觀中。
