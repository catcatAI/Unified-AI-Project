# 角色系統 (Character System)

## 角色類型

遊戲中有三種角色類型：

| 類型 | 代碼 | 說明 | 控制者 |
|------|------|------|--------|
| PC | Player Character | 玩家操控的角色 | 玩家 |
| NPC | Non-Player Character | AI 驅動的角色 | AI / GM |
| GM | Game Master | 遊戲主持人 | Angela AI |

### PC — 玩家角色

PC 可以：
- 從現有 NPC 中選擇並扮演
- 或使用角色卡新建一個自定義角色
- 控制角色在世界中移動、互動

### 角色卡與世界觀生成（根據實際卡片堆數據）

#### 卡片堆概覽

| 卡片類型 | 數量 | 說明 |
|----------|------|------|
| 角色卡 | 59 | CC-01 ~ CC-67 + CCK-01，全部角色原型 |
| 場景卡 | 24 | 場景定義（S01~S17, SC-01, SC-20~SC-24） |
| 劇情節點卡 | 76 | 故事節點 |
| 組織卡 | 16 | 勢力/公會 |
| 規則卡 | 15 | 遊戲規則 |
| 故事線卡 | 11 | 劇情線 |
| 國家卡 | 7 | 國家/勢力設定 |
| 世界觀核心卡 | 1 | CCK-01 克洛諾斯 |

#### 角色卡是框架模板

根據實際卡片堆數據：

- 59 張角色卡是框架模板，不是特定世界中的具體角色
- 每張角色卡有 `tokens` 字段，定義该角色的能力框架（13 種 token 類別）
- 提取差異是「有或沒有」：某張卡有「combat」token 就是戰士原型，沒有就是非戰士
- 沒有固定的種族/物種欄位：角色的「種族」由其 token 組合決定
- **vitality** 是最核心的 token，75 張角色卡擁有——這是「勇者原型」的標誌

| Token 類別 | 出現次數 | 對應屬性 |

#### 角色原型分類（按 token 組合）

| 原型 | 特徵 token | 對應遊戲角色 | 卡片數量 |
|------|-----------|-------------|----------|
| 勇者 (combat + vitality) | 戰鬥+生命力 | 主力戰鬥角色、英雄 | 約 40+ |
| 村民 (vitality only, 無 combat) | 僅生命力 | 日常NPC、村民、商販 | 部分 |
| 工匠/製作者 (craft + relation) | 製作+社交 | 工坊主人、商人 | 約 8+ |
| 學者/知識者 (knowledge + lore) | 知識+學識 | 圖書館員、教師 | 約 6+ |
| 特殊能力者 (element + energy) | 元素+能量 | 術士、魔法使用者 | 約 5+ |
| 社交者 (social + relation) | 社交+關係 | 使者、間諧者 | 約 4+ |

#### 隱藏世界觀與動態生成

- 卡片堆的角色卡是框架原型，可以放入任意世界觀中生成了勇者或村民
- 角色卡沒有綁定特定世界——可以動態生成到隱藏世界觀中
- 缺少的 token 可以自由補充——系統是開放的

#### PC 選擇與新建

- **選擇現有 NPC**：從 59 張角色卡中選擇一個原型作為 PC
- **新建角色卡**：自行分配 token、選擇技能、生成名稱，建立全新的角色原型
- 兩種方式都基於卡片堆的框架系統

### NPC — 非玩家角色

每個 NPC 有以下屬性：
- **基本資訊**：名稱、身份、描述
- **例行程為**：根據時間的不同，NPC 會在固定地點執行活動
- **對話池**：根據好感度和時間變化
- **好感度**：影響 NPC 對玩家的態度和可選行為
- **角色卡**：NPC 來自特定卡片（card_id）

NPC 角色有獨立的「生活圈」：
`
[起床] → [工作/活動] → [午餐] → [下午活動] → [休息] → [睡眠]
  06:00      10:00       12:00      14:00       20:00     22:00
`

### GM — 遊戲主持人

GM 由 Angela AI 驅動，負責：
- 場景描述生成
- NPC 對話生成
- 事件觸發與裁決
- 戰鬥主持
- 故事推進

## 角色立繪系統 (Symbol Portrait)

遊戲中的角色立繪**不是圖片**，而是由符號組成的文字藝術。這是 CLI 遊戲的核心設計決策。

### 立繪設計規則

`
PC 角色 (符號組成):     NPC 角色 (符號組成):
  ██╗    ██╗              ╔═╗  ╔═╗
 ╚═╝    ╚═╝              ║█║  ║█║
  ╔═╗  ╔═╗               ║█║  ║█║
  ║█║  ║█║               ╚═╝  ╚═╝
  ╚═╝  ╚═╝
`

- 使用 █ (塊狀)、║ (豎線)、═ (橫線) 等 ASCII 符號
- 不同職業有不同符號組合（戰士、工匠、術士、商人等）
- 表情狀態使用臉部符號：
  - ◕ ω ◕ — 快樂
  - ◔ ω ◔ — 中性
  - ◒ ω ◒ — 悲傷
  - ◐ ω ◐ — 憤怒
  - ○ ω ○ — 恐懼
  - ◎ ω ◎ — 專注

### 裝備時的立繪變化

當角色裝備不同物品時，立繪會在對應位置附加符號標記：
`
PC (持劍):              PC (穿戴鎧甲):
  ██╗    ██╗              ██╗    ██╗
 ╚═╝    ╚═╝              ║█║    ║█║  ← 武器符號
  ╔═╗  ╔═╗ ⚔️            ╚═╝  ╚═╝ ← 盔甲符號
  ║█║  ║█║                 
  ╚═╝  ╚═╝                 
`

### NPC 立繪規則

- 根據角色卡中的 visual 字段生成符號
- 不同職業類型有預設符號模板
- NPC 出場時顯示立繪，離場時隱藏

## 三色屬性條系統

### 🔴 紅條 (身體狀態)

代表角色的物理身體狀態。

#### 主屬性

| 屬性 | 說明 | 初始值 |
|------|------|--------|
| HP (血量) | 生命值，歸零則昏迷/死亡 | 100 |
| max_hp | HP 上限 | 100 |
| 身體 (body) | 身體強度，影響物理傷害 | 1.0 |
| 肢體 (limbs) | 肢體完整性，每個肢體獨立 | 100 |

#### 肢體系統

角色有 6 個肢體，每個可獨立受損：
| 肢體 | ID | 影響 |
|------|-----|------|
| 頭部 | head | 頭部受損影響視力和理智 |
| 軀幹 | torso | 軀幹受損影響所有行動 |
| 左臂 | left_arm | 左手無法裝備/使用物品 |
| 右臂 | right_arm | 右手無法裝備/使用物品 |
| 左腿 | left_leg | 移動速度減半 |
| 右腿 | right_leg | 移動速度減半 |

肢體 health ≤ 0 = 該肢體失去功能（如手臂毀損無法使用武器）

#### 額外狀態

| 狀態 | 說明 |
|------|------|
| 疲勞度 (fatigue) | 0-100，越高越虛弱，>80 速度減半 |
| 痛覺 (pain) | 0-100，影響行動能力，>60 有機率無法行動 |
| 出血率 (bleed_rate) | 每回合自動扣 HP |

### 🔵 藍條 (靈活躍度)

代表個體靈的清醒與活躍程度。

#### 主屬性

| 屬性 | 說明 | 初始值 |
|------|------|--------|
| spirit_activity | 靈活躍度 (0.0=沉睡, 1.0=完全活躍) | 1.0 |
| max_spirit | 靈力上限 | 100 |
| current_spirit | 當前靈力 | 100 |
| stamina | 體力 (物理行動消耗) | 100 |
| max_stamina | 體力上限 | 100 |

#### 靈系屬性

| 屬性 | 說明 |
|------|------|
| willpower | 意志力 — 干涉強度的核心因素 |
| focus | 專注力 — 精細干涉的能力 |
| affinity | 共鳴度 — 與環境靈的亲和性 |
| inertia | 累積惰性 — 連續干涉產生的阻力 |
| exhaustion | 靈疲憊度 (0=精神飽滿) |
| resonance_level | 共鳴等級 |

### 🟢 綠條 (經歷狀態)

代表角色的成長與經歷。

#### 主屬性

| 屬性 | 說明 | 初始值 |
|------|------|--------|
| level | 角色等級 | 1 |
| exp | 當前經驗值 | 0 |
| exp_to_next | 升級所需經驗 | 100 |
| skills | 技能字典 | 空 |
| reputation | 聲望字典 | 空 |
| achievements | 成就列表 | 空 |
| history | 歷史記錄 | 空列表 |

#### 技能系統

技能按類別分類：
- combat — 戰鬥技能
- craft — 製作技能
- social — 社交技能
- exploration — 探索技能
- knowledge — 學識技能

每個技能有 level、exp、max_level，技能經驗通過使用增長。

## 角色卡與世界觀生成

### 角色卡是框架模板

遊戲的角色卡來自卡片堆（card deck），其本質是**框架模板**，不是特定世界中的具體角色：

- 卡片堆中的設定文本大多是**框架性的**（屬性類別、技能類型、能力系統）
- 提取差異時是判斷「**有或沒有**」，不是判斷「**多或少**」
- 缺少的設定可以自由補充——系統本身支持動態生成

### 角色卡 = 勇者原型 + 村民原型

從卡片堆提取的角色按原型分類：

| 原型 | 說明 | 來源 |
|------|------|------|
| **勇者** (hero archetype) | 角色卡多為勇者類型——有戰鬥能力、探索能力、特殊技能 | 從隱藏世界觀中提取 |
| **村民** (villager archetype) | 日常NPC——工匠、商人、學生、守衛等，能力較弱但各有特色 | 從隱藏世界觀中提取 |
| **特殊角色** (special archetype) | 如「概念調味師」「阿拉克涅見習生」等帶有独特能力的角色 | 從世界觀核心卡延伸 |

### 隱藏世界觀與動態生成

- 角色卡來自「**不知道多少隱藏**」的世界觀——這些世界觀可能不存在於已知設定中，但卡片堆的支持結構可以生成它們
- 角色卡是從隱藏世界觀中「**抽（想）出來**」的代表——不是已存在的角色，而是可以生成的角色模板
- 想象一下：59張角色卡，每一張都是一個**原型**，可以放入任意的勇者世界、村落世界、或其他隱藏世界觀中生成了勇者或村民
- 有什麼能力就有什么角色，沒有的可以補上——系統是開放的，不是封閉的世界觀

### PC 可從現有 NPC 選擇，或新建角色卡

- **選擇現有 NPC**：從卡片堆中已有的角色原型選擇一個作為 PC（直接從 NPC 列表選）
- **新建角色卡**：自行分配屬性、選擇技能、生成名稱，建立全新的角色原型
- 兩種方式都基於卡片堆的框架系統

### 角色卡新建流程

玩家新建角色卡的流程：
1. 選擇種族（人類、獸人等，或從隱藏世界觀中選擇）
2. 分配初始屬性點（紅/藍/綠條）
3. 選擇初始技能（最多3個，從框架模板中選擇）
4. 選擇或生成角色名稱
5. 系統根據角色卡模板生成角色立繪符號
6. 生成初始裝備和物品
7. 開始遊戲
