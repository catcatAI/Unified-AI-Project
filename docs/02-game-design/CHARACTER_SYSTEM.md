# 角色系統 (Character System)

## 角色類型

遊戲中有三種角色類型：

| 類型 | 代碼 | 說明 | 控制者 |
|------|------|------|--------|
| PC | Player Character | 玩家操控的角色 | 玩家 |
| NPC | Non-Player Character | AI 驅動的角色 | AI / GM |
| GM | Game Master | 遊戲主持人 | Angela AI |

### PC — 玩家角色

PC 可以：
- 從現有 NPC 中選擇並扮演
- 或使用角色卡新建一個自定義角色
- 控制角色在世界中移動、互動

PC 的初始屬性根據所選角色卡決定，或通過新建角色卡時分配屬性點。

### NPC — 非玩家角色

每個 NPC 有以下屬性：
- **基本資訊**：名稱、身份、描述
- **例行程為**：根據時間的不同，NPC 會在固定地點執行活動
- **對話池**：根據好感度和時間變化
- **好感度**：影響 NPC 對玩家的態度和可選行為
- **角色卡**：NPC 來自特定卡片（card_id）

NPC 角色有獨立的「生活圈」：
`
[起床] → [工作/活動] → [午餐] → [下午活動] → [休息] → [睡眠]
  06:00      10:00       12:00      14:00       20:00     22:00
`

### GM — 遊戲主持人

GM 由 Angela AI 驅動，負責：
- 場景描述生成
- NPC 對話生成
- 事件觸發與裁決
- 戰鬥主持
- 故事推進

## 角色立繪系統 (Symbol Portrait)

遊戲中的角色立繪**不是圖片**，而是由符號組成的文字藝術。這是 CLI 遊戲的核心設計決策。

### 立繪設計規則

`
PC 角色 (符號組成):     NPC 角色 (符號組成):
  ██╗    ██╗              ╔═╗  ╔═╗
 ╚═╝    ╚═╝              ║█║  ║█║
  ╔═╗  ╔═╗               ║█║  ║█║
  ║█║  ║█║               ╚═╝  ╚═╝
  ╚═╝  ╚═╝
`

- 使用 █ (塊狀)、║ (豎線)、═ (橫線) 等 ASCII 符號
- 不同職業有不同符號組合（戰士、工匠、術士、商人等）
- 表情狀態使用臉部符號：
  - ◕ ω ◕ — 快樂
  - ◔ ω ◔ — 中性
  - ◒ ω ◒ — 悲傷
  - ◐ ω ◐ — 憤怒
  - ○ ω ○ — 恐懼
  - ◎ ω ◎ — 專注

### 裝備時的立繪變化

當角色裝備不同物品時，立繪會在對應位置附加符號標記：
`
PC (持劍):              PC (穿戴鎧甲):
  ██╗    ██╗              ██╗    ██╗
 ╚═╝    ╚═╝              ║█║    ║█║  ← 武器符號
  ╔═╗  ╔═╗ ⚔️            ╚═╝  ╚═╝ ← 盔甲符號
  ║█║  ║█║                 
  ╚═╝  ╚═╝                 
`

### NPC 立繪規則

- 根據角色卡中的 visual 字段生成符號
- 不同職業類型有預設符號模板
- NPC 出場時顯示立繪，離場時隱藏

## 三色屬性條系統

### 🔴 紅條 (身體狀態)

代表角色的物理身體狀態。

#### 主屬性

| 屬性 | 說明 | 初始值 |
|------|------|--------|
| HP (血量) | 生命值，歸零則昏迷/死亡 | 100 |
| max_hp | HP 上限 | 100 |
| 身體 (body) | 身體強度，影響物理傷害 | 1.0 |
| 肢體 (limbs) | 肢體完整性，每個肢體獨立 | 100 |

#### 肢體系統

角色有 6 個肢體，每個可獨立受損：
| 肢體 | ID | 影響 |
|------|-----|------|
| 頭部 | head | 頭部受損影響視力和理智 |
| 軀幹 | torso | 軀幹受損影響所有行動 |
| 左臂 | left_arm | 左手無法裝備/使用物品 |
| 右臂 | right_arm | 右手無法裝備/使用物品 |
| 左腿 | left_leg | 移動速度減半 |
| 右腿 | right_leg | 移動速度減半 |

肢體 health ≤ 0 = 該肢體失去功能（如手臂毀損無法使用武器）

#### 額外狀態

| 狀態 | 說明 |
|------|------|
| 疲勞度 (fatigue) | 0-100，越高越虛弱，>80 速度減半 |
| 痛覺 (pain) | 0-100，影響行動能力，>60 有機率無法行動 |
| 出血率 (bleed_rate) | 每回合自動扣 HP |

### 🔵 藍條 (靈活躍度)

代表個體靈的清醒與活躍程度。

#### 主屬性

| 屬性 | 說明 | 初始值 |
|------|------|--------|
| spirit_activity | 靈活躍度 (0.0=沉睡, 1.0=完全活躍) | 1.0 |
| max_spirit | 靈力上限 | 100 |
| current_spirit | 當前靈力 | 100 |
| stamina | 體力 (物理行動消耗) | 100 |
| max_stamina | 體力上限 | 100 |

#### 靈系屬性

| 屬性 | 說明 |
|------|------|
| willpower | 意志力 — 干涉強度的核心因素 |
| focus | 專注力 — 精細干涉的能力 |
| affinity | 共鳴度 — 與環境靈的亲和性 |
| inertia | 累積惰性 — 連續干涉產生的阻力 |
| exhaustion | 靈疲憊度 (0=精神飽滿) |
| resonance_level | 共鳴等級 |

### 🟢 綠條 (經歷狀態)

代表角色的成長與經歷。

#### 主屬性

| 屬性 | 說明 | 初始值 |
|------|------|--------|
| level | 角色等級 | 1 |
| exp | 當前經驗值 | 0 |
| exp_to_next | 升級所需經驗 | 100 |
| skills | 技能字典 | 空 |
| reputation | 聲望字典 | 空 |
| achievements | 成就列表 | 空 |
| history | 歷史記錄 | 空列表 |

#### 技能系統

技能按類別分類：
- combat — 戰鬥技能
- craft — 製作技能
- social — 社交技能
- exploration — 探索技能
- knowledge — 學識技能

每個技能有 level、exp、max_level，技能經驗通過使用增長。

## 角色卡新建系統

玩家可以新建角色卡，流程如下：

`
1. 選擇種族 (人類、獸人等)
2. 分配初始屬性點 (紅/藍/綠條)
3. 選擇初始技能 (最多3個)
4. 選擇或生成角色名稱
5. 系統生成角色立繪符號
6. 生成初始裝備和物品
7. 開始遊戲
`
