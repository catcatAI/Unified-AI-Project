### 主線劇情結構

遊戲分為多部（Act），每部含多個場景與選擇支線。

#### Act 1: 日常篇
- 玩家在鏡湖村莊醒來
- 認識村莊中的 NPC
- 完成日常任務（物品收集、幫助村民）
- 開始建立 NPC 關係

#### Act 2: 探索篇  
- 深入探索村莊周邊場景（森林、礦山、湖畔）
- 發現隱藏場景（廢棄實驗室、廢棄房屋）
- 遇到更多 NPC，建立更深關係
- 接觸世界線深層的謎團

#### Act 3: 迴廊篇
- 進入地下迴廊系統
- 面對內在恐懼與選擇的鏡像
- 通過多道門（每道門代表不同選擇主題）
- 探索迴廊的深層秘密

#### Act 4: 結局篇
- 根據玩家選擇走向不同結局
- 多重結局分支（回歸、停留、深層探索、攜NPC同行）
- 各結局反映玩家的旅程選擇


## 任務系統 (Quest System)

任務（Quest）是遊戲的核心驅動系統，擁有完整的因果鏈、時間門控、角色條件與多樣化的任務類型。

### 任務的因果關係（Causal Chain）

每個任務的設計遵循因果關係原則：

```
為什麼你能接到這個任務？
  ├── 角色條件：種族、等級、Token類別、技能等級
  ├── 世界條件：時間（小時）、地點、天氣
  ├── 社交條件：與NPC的好感度、聲望等級
  └── 進度條件：前置任務完成、世界狀態

為什麼任務能完成？
  ├── 客觀條件：收集足夠物品、擊敗足夠敵人、造訪地點
  ├── 時間條件：在指定時間內完成 / 在特定時間到達
  ├── 社交條件：與NPC建立足夠好感度
  └── 技能條件：擁有足夠技能等級
```

#### 因果鏈範例

```
MQ-01 (鏡湖的秘密)
  └─ 條件: 聲望≧0 (任何人)
  └─ 完成: visit鏡湖 + collect水晶碎片
  └─ 解鎖: MQ-02

MQ-02 (大正浪漫的迴響)
  └─ 條件: 完成MQ-01, Lv≧3
  └─ 完成: visit秘密鐵工廠 + collect鐵錠×3 + collect魔法粉
  └─ 解鎖: MQ-03

MQ-03 (圖書館之謎)
  └─ 條件: 完成MQ-02, Lv≧5
  └─ 完成: visit中央大圖書館 + visit英靈殿
  └─ 解鎖: MQ-04

SQ-02 (強化作戰 — 小狐丸)
  └─ 條件: 小狐丸好感≧20, 6時≦時間<18時(小狐丸在巡視時)
  └─ 完成: collect鐵礦×4
  └─ 解鎖: SQ-08 (驅除暗影)
```

### 任務資料結構

每個任務的定義包含以下字段：

```python
{
    "id": "MQ-01",          # 唯一ID
    "title": "鏡湖的秘密",    # 標題
    "type": "main",          # main / side / daily / event
    "giver": "系統",         # 給予者NPC名稱
    "desc": "探索鏡湖...",    # 描述
    
    # 因果條件 — 誰能接、何時能接
    "conditions": {
        "required_race": "",          # 需要的種族 (空白=不限)
        "required_level": 0,          # 最低等級
        "required_tokens": [],        # 需要的token類別
        "required_skill": {"craft": 3}, # 需要的技能等級
        "required_reputation": 0,     # 最低聲望
        "required_relationships": {}, # {NPC名: 好感度}
        "required_quests": [],        # 必須已完成的前置任務
        "required_world_state": {},   # 世界狀態條件
        "time_available": {           # 可接取時間窗口
            "start_hour": 0,
            "end_hour": 24
        },
        "giver_activity": "",        # 給予者需要的活動狀態
        "giver_location": "",        # 給予者在哪個地點
    },
    
    "objectives": [
        # 每個目標支援不同類型
        {
            "type": "collect",       # visit/collect/defeat/delivery/escort/
                                       # craft/social/explore/gather_info/timed
            "target": "水晶碎片",
            "qty": 1,
            "detail": "收集水晶碎片",
            "alt_item": "",          # 可替代物品
            "time_limit_hours": 0,    # 0=無時間限制
        },
    ],
    
    # 失敗條件
    "failure": {
        "timeout_hours": 0,           # 0=無時限
        "on_fail": "remove",          # remove(移除)/restart(重來)/penalty(懲罰)
        "penalty": {"gold": -20, "rep": -5},  # 失敗懲罰
    },
    
    # 獎勵
    "reward_exp": 80,
    "reward_gold": 30,
    "reward_item": "古老鑰匙",
    "reward_reputation": 10,         # 完成後聲望
    "reward_relationships": {"小狐丸": 15},  # 完成後好感
    
    # 鏈接
    "next_quest": "MQ-02",           # 完成後解鎖的任務
}
```

### 任務類型 (Objective Types)

| 類型 | 說明 | 例子 |
|------|------|------|
| `visit` | 造訪指定地點 | 前往鏡湖 |
| `collect` | 收集指定物品 | 收集5個草藥 |
| `defeat` | 擊敗指定敵人 | 擊敗2隻暗影靈 |
| `delivery` | 運送物品給NPC | 將鐵錠送給左間小蒼蘭 |
| `escort` | 護送NPC到目的地 | 護送商人到西翼大市集 |
| `craft` | 合成指定物品 | 合成一把鐵劍 |
| `social` | 與NPC建立好感 | 與小狐丸好感達到30 |
| `explore` | 探索/發現隱藏地點 | 發現廢棄礦坑的秘密 |
| `gather_info` | 從NPC打聽情報 | 向3個NPC打聽鏡湖消息 |
| `timed` | 在時限內完成 | 在天黑前回到城鎮 |
| `use_skill` | 使用特定技能 | 用鍛造技能修理裝備 |

### 任務類型 (Quest Types)

| 類型 | ID前綴 | 說明 | 生成方式 |
|------|--------|------|----------|
| 主線任務 | MQ- | 推動主線劇情的任務 | 手寫定義，有完整因果鏈 |
| 支線任務 | SQ- | 可選的支線任務 | 手寫定義，有NPC關聯 |
| 劇情節點 | SN- | 從76張劇情節點卡生成 | 自動生成，與卡片內容相關 |
| NPC任務 | NPC- | 由NPC根據其特質生成 | 自動生成，基於NPC的token類別 |
| 公會任務 | GQ- | 從組織卡生成的任務 | 自動生成，基於組織類別 |
| 每日任務 | DQ- | 每天重置的簡單任務 | 自動生成，低獎勵 |
| 事件任務 | EQ- | 天氣/時間觸發的任務 | 動態觸發 |

### 時間門控系統

任務的接取與完成受遊戲內時間影響：

```
時間門控規則:
  - NPC只在特定時間給予特定任務 (eg. 小狐丸只在巡視時給SQ-02)
  - 某些任務只能在特定時間完成 (eg. 夜晚才能遇到幽靈)
  - 有時間限制的任務 (eg. 在天黑前送達)
  - 每日任務在每天0點刷新

時間門控範例:
  SQ-02 (強化作戰): 小狐丸在6:00~18:00巡視時才能接
  SQ-04 (森林巡邏): 只能在白天接 (6:00~18:00)
  SQ-08 (驅除暗影): 只能在夜晚遇到暗影靈 (18:00~6:00)
  DQ-01 ~ DQ-05: 每日任務，每天0點重置
```

### NPC 關係系統

- 每一 NPC 都有一獨立的 disposition 值（-100~100）
  - 低於-50: 敵對
  - -50~0: 敵意
  - 0~20: 冷淡
  - 20~50: 中立
  - 50~80: 友好  
  - 80~100: 親密
- 好感度會隨玩家行動改變（贈送物品、對話、任務完成）
- 不同好感度級別解鎖不同對話選項與任務
- 關係影響 NPC 是否願意提供幫助、任務、或同行

### 時間系統

- 遊戲以「小時」為基本時間單位
- 每個玩家行動消耗 1 小時
- 不同時間影響 NPC 的狀態（工作、休息、活動）
- NPC 例行公事與時間綁定
- 任務有時間窗口限制（只能在特定時間接取）
- 任務可能有完成時限（如天黑前）
- 每日任務每天0點重置
