# CLI 終端介面設計 (Interface — Terminal Presentation)

## 說明

本文件描述遊戲在**終端機 (CLI/Terminal)** 中的呈現方式。本遊戲**不包含 UI**，所有呈現均為純文字符號在終端中顯示。

### 呈現原則

1. **純文字**：所有內容為文字符號，包括角色立繪（符號組成，非圖片）
2. **無圖形元素**：不使用任何圖形库渲染（如 pygame、Pygame 等）
3. **終端原生**：直接在終端機中顯示，無需瀏覽器或 GUI
4. **ASCII 符號**：使用 ASCII 字符和 Unicode 符號構建視覺元素

### 符號立繪 (Symbol Portrait)

角色立繪由 ASCII/Unicode 符號組成，非圖片。不同角色有不同符號組合：

`
PC (玩家):        NPC (商人):       NPC (戰士):
  ██╗    ██╗        ╔═╗  ╔═╗          ╔═╗  ╔═╗
 ╚═╝    ╚═╝        ║█║  ║█║          ║█║  ║█║
  ╔═╗  ╔═╗         ║█║  ║█║          ║█║  ║█║
  ║█║  ║█║         ╚═╝  ╚═╝          ║█║  ║█║
  ╚═╝  ╚═╝                        ╚═╝  ╚═╝
`

符號規則：
- █ 用於填充（代表實體/身體）
- ║ 用於四肢
- ═ 用於連接線
- ╔ ╗ ╚ ╝ 用於外框
- 表情符號：◕ ω ◕ (快樂)、◔ ω ◔ (中性)、◒ ω ◒ (悲傷)
- HP 低時符號變暗或出現 ✦ 傷痕符號

### CLI 呈現規則

1. **清屏**：每次畫面更新前清除終端內容
2. **寬度**：以 60-80 字元為準，自动換行
3. **色彩**：使用終端 ANSI 色彩代碼
   - 🔴 紅色 (\033[31m) — 紅條 (HP)
   - 🔵 藍色 (\033[34m) — 藍條 (靈力)
   - 🟢 綠色 (\033[32m) — 綠條 (經驗)
   - ⚪ 白色 — 敘事文字
   - 🟡 黃色 — 系統訊息
   - 🔵 青色 — NPC 對話
   - 🔘 灰色 — 提示/選項
4. **換行**：敘事文字自動換行至 60 字元寬
5. **分隔線**：使用 ══ 或 ── 等線條符號分隔不同區域

### 指令輸入規則

- 命令行以 >  為提示符
- 支持數字選單 (1-8) 或直接輸入指令文字
- 中文指令優先（因為遊戲以中文為主語言）
- 快捷指令：q / quit / exit 退出遊戲

### 不應使用 UI

以下項目不應以 UI 方式實現：

| 不該用 UI 元素 | 而是用 CLI 替代 |
|----------------|-----------------|
| 圖片/立繪    | 符號組成的文字立繪 |
| 圖形面板     | ASCII 框線 + 文字 |
| 按鈕         | 數字選單或文字指令 |
| 滑鼠操作      | 鍵盤輸入 |
| 彈出視窗      | 終端文字輸出 |
| 動畫效果      | 文字轉場效果 |
| 音效          | 靜音 (CLI 無音訊) |
