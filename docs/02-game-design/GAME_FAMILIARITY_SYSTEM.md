# Familiarity System — NPC 互動與資訊揭露

## 概述

熟悉度系統控制 PC 對 NPC 的「認知深度」。初見 NPC 時，PC 只知道模糊的外觀描述。隨著互動次數增加，逐漸解鎖 NPC 的姓名、種族、背景、能力、秘密。

## 熟悉度等級

| Lv | 名稱 | XP門檻 | 解鎖資訊 | 玩家看到的內容 |
|----|------|--------|----------|---------------|
| 0 | 未知 | 0 | 無 | [神秘的貓娘法師] — 模糊的外觀描述標籤 |
| 1 | 初識 | 6 | 姓名 + 種族 | 千島 雉 (貓娘) |
| 2 | 知悉 | 20 | 角色定位 + 交易物品 | 千島 雉 — 紫水晶持有者，8歲領袖 |
| 3 | 熟悉 | 50 | 完整描述 + 所有能力 | 展示完整描述、能力列表 |
| 4 | 親密 | 100 | 行程 + 深層敘事標籤 | 展示 NPC 的活動地點與 token 分類 |
| 5 | 羈絆 | 180 | 秘密 + 關係獎勵 | 解鎖隱藏對話與特殊互動 |

## 模糊描述標籤生成規則

當熟悉度 Lv 0 時，NPC 名稱顯示為模糊描述標籤：

```
[前綴 + 種族 + 職業]
```

- **前綴**：根據職業自動選擇（戰士→沉穩的、商販→精明的、法師→神秘的……）
- **種族**：從 NPC 的 race 欄位提取（貓娘、人類、妖精……）
- **職業**：從 archetype 映射（warrior→戰士, merchant→商販, mage→法師……）

範例：
- `[神秘的貓娘法師]` — 千島 雉（初見）
- `[精明的狐狸商販]` — 小狐丸（初見）
- `[沉穩的人類管家]` — 千島 忠臣（初見）

## XP 獲取方式

| 動作 | XP | 觸發時機 |
|------|----|---------|
| 打招呼 | 3 | NPC 對話選項 1 |
| 交流 | 8 | NPC 對話選項 2（消耗 SP-10） |
| 送禮物 | 12 | NPC 對話選項 3 |
| 完成任務 | 20 | 接受並完成 NPC 的任務 |
| 特殊事件 | 30 | 劇情觸發的特殊互動 |

## 升級通知

每次熟悉度升級時，系統顯示對應訊息：

- **Lv 1**: 「你開始記住這個人的模樣了——對方叫%s。」
- **Lv 2**: 「你和%s聊過幾次，大概知道對方是做什麼的。」
- **Lv 3**: 「你已經很熟悉%s了——對方的能力與經歷你都了解。」
- **Lv 4**: 「你和%s之間有著深厚的信任。你知道對方的習慣與秘密。」
- **Lv 5**: 「羈絆——你與%s之間有著超越言語的連結。」

## 與既有系統的關係

### 聲望（Reputation）
- **聲望** = 全局數值 (-100~100)，影響 NPC 對 PC 的態度（敵意→友好）
- **熟悉度** = 逐 NPC 數值 (Lv 0~5)，影響 PC 對 NPC 的認知
- 兩者獨立運作：可以聲望高但熟悉度低（NPC 對你好但你還不認識他）

### 好感度（Relationship）
- **好感度** = 逐 NPC 數值 (-100~100)，影響任務解鎖與特殊互動
- 隨著互動（打招呼+2、交流+5、送禮+8~10）累積
- 熟悉度與好感度同步增加（因為熟悉度提升需要互動）

### 存檔
- 熟悉度儲存在 `character["familiarity"]`，自動隨 JSON 存檔/讀檔
- `create_blank_character()` 預設 `"familiarity": {}`
- `init_familiarity(character)` 確保 key 存在（新角色/舊存檔相容）
