# 物品與裝備系統 (Item & Equipment System)

## 物品系統

### 物品分類

| 分類 | 說明 | 範例 |
|------|------|------|
| weapon | 武器 | 劍、弓、法杖 |
| armor | 防具 | 鎧甲、頭盔、盾牌 |
| consumable | 消耗品 | 藥水、乾糧 |
| material | 材料 | 鐵礦、木材、皮革 |
| quest | 任務物品 | 鑰匙、地圖 |
| misc | 其他 | 鑰匙、紙條 |

### 物品屬性

每個物品有以下屬性：

- **屬性乘區**：如武器增加力量 (+0.1)、耐甲增加體質 (+0.1)
  - 正數 = 增益，負數 = 減益
  - 多個乘區疊加（加法）
- **耐久**：裝備與工具均有耐久值
  - 每次使用消耗 1 点耐久
  - 耐久歸零 = 裝備失效（屬性加成歸零）
  - 可修復或丟棄
- **堆疊**：可疊加物品有 max_stack 設限（如藥水堆疊 20）
- **稀有度**：common, uncommon, rare, epic, legendary
- **元素**：fire, ice, lightning, earth, 或空
- **價格**：買價/賣價
- **可使用**：消耗品標記，標記 use_effect

### 物品欄管理

- 最大欄位：20 格
- 最大負重：50 kg
- 物品有重量，總重不可超過上限
- 堆疊檢查：同 item_id 優先疊加
- 任務物品鎖定不可丟棄

`
物品欄操作：
- 添加物品 (add_item) → 堆疊檢查或新格子
- 移除物品 (remove_item) → 減量或刪除格子
- 檢查擁有 (has_item) → 總數比較
- 查看物品欄 → 顯示所有格子 + 當前負重
`

## 裝備欄系統

### 裝備欄位 (12 欄)

| 欄位 ID | 名稱 | 可裝備類型 |
|---------|------|------------|
| head | 頭部 | 防具、飾品 |
| face | 面部 | 防具、飾品 |
| neck | 頸部 | 飾品 |
| torso | 軀幹 | 防具 |
| left_arm | 左臂 | 防具 |
| right_arm | 右臂 | 防具 |
| left_hand | 左手 | 武器/工具/盾牌 |
| right_hand | 右手 | 武器/工具/盾牌 |
| waist | 腰部 | 飾品/收納 |
| legs | 腿部 | 防具 |
| feet | 腳部 | 防具 |
| back | 背部 | 防具/收納 |

### 裝備操作

- **裝備 (equip)**：將物品裝入指定欄位，返回被替換的舊物品
- **卸下 (unequip)**：從欄位移除物品，返回卸下物品
- **屬性乘區合計**：get_stat_bonuses() 計算所有裝備的屬性加成總和
- **裝備時消耗耐久**，卸下時恢復少量耐久

### 屬性乘區 (Stat Multipliers)

裝備的 stat_multipliers 影響角色屬性：
- +0.1 = 該屬性 +10%
- -0.05 = 該屬性 -5%
- 在角色最終屬性計算時疊加

## 耐久系統

### 耐久等級對照

| 耐久比例 | 狀態名稱 | 效能 |
|---------|---------|------|
| 80-100% | 完好 | 100% 效能 |
| 60-80% | 輕微磨損 | 90% 效能 |
| 40-60% | 中度磨損 | 75% 效能 |
| 20-40% | 嚴重磨損 | 50% 效能 |
| 1-20% | 瀕臨損壞 | 25% 效能 |
| 0% | 已損壞 | 0% 效能（失效） |

### 耐久計算

- 所有裝備的基礎耐久由材質決定
  - 金屬：基礎 100
  - 皮革：基礎 60
  - 木質：基礎 40
- 戰鬥受擊：消耗額外耐久（5-15）
- 普通使用：消耗 1 點耐久
- 修復：使用修復工具或商販修復

## 合成系統

### 合成類別

| 類別 | 說明 | 範例 |
|------|------|------|
| combine (組合) | 兩物品合為一物 | 魔法石 + 劍 = 附魔劍 |
| process (加工) | 原材料變成品 | 鐵礦 → 鐵錠 |
| craft (製作) | 用配方製作 | 布料 + 染料 → 紅袍 |
| alchemize (煉金) | 混合多材料，隨機結果 | 三種藥草 → 治療藥水 |

### 配方結構

`python
Recipe:
  recipe_id: unique ID
  name: 配方名稱
  category: combine | process | craft | alchemize
  ingredients: list of (item_id, quantity, consumed)
  result_item_id: 產出物品 ID
  result_quantity: 產出數量
  required_skill: 需要技能名稱
  required_skill_level: 需要技能等級
  required_station: 需要工作台/場所
  crafting_time: 合成時間（回合）
  failure_chance: 失敗機率 (0.0-1.0)
  failure_result: 失敗時的結果
`

## 載具系統 (Vehicle System)

載具是可互動物件，可在場景間快速移動：

| 屬性 | 說明 |
|------|------|
| speed | 移動速度倍率 |
| capacity | 載人數 |
| cargo_capacity | 貨物容量 (kg) |
| fuel | 燃料/體力 |
| condition | 車況 (0-100) |
| equipment_slots | 載具可裝備的部件 |

載具可被騎乘操作，也可作為場景物件互動。
