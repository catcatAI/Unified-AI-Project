# 模擬系統 (Simulation Systems)

## 概述

本遊戲不僅是冒險遊戲，核心特色在於**模擬**。NPC 有獨立的生活圈、日程表、作息和社交關係，世界會依據時間推移而動態變化。

## NPC 生活圈與作息

### 作息系統 (NPCRoutine)

每個 NPC 都有自己的作息表，根據遊戲時間 (0-23 小時) 在不同地點執行不同活動。

```
作息表範例 (小狐丸):
  06:00 - 10:00 : 在火山口岩洞整理冰晶 (鏡湖火山口) - calm
  10:00 - 14:00 : 巡視鏡湖周邊 (鏡湖) - alert
  14:00 - 18:00 : 在岩洞中休息 (鏡湖火山口) - rest
  18:00 - 22:00 : 與左間小蒼蘭交流 (秘密鐵工廠) - friendly
  22:00 - 06:00 : 睡眠 (鏡湖火山口) - sleep
```

### 生活圈規則

1. **時間驅動**: NPC 的活動完全由遊戲時間決定
2. **位置追蹤**: 每個 NPC 隨身攜帶 current_location，根據作息表自動更新
3. **心情系統**: NPC mood 受活動和時間影響
   - sleep → 疲憊
   - rest → 平復
   - work → 專注
   - social → 愉快
4. **巡邏規則**: 部分 NPC (如守衛) 會在特定路線巡邏

### 生命週期事件

NPC 可能發生以下事件：
- **相遇**: 在場景中遇到 NPC 觸發對話
- **求助**: NPC 主動請求幫助 (好感度高時)
- **交易**: NPC 提供買賣物品服務
- **任務**: NPC 發放任務給玩家
- **離開**: 特定時間 NPC 離開場景

## 社交模擬

### 好感度系統

```
disposition (disposition value):
  0-20   : 敵意 (敵對、反對、攻擊)
  20-50  : 冷淡 (不熱情、有限互動)
  50-80  : 友好 (樂於助人、分享資訊)
  80-100 : 親密 (特殊對話、贈送、任務同行)
```

### 好感度影響

| 好感度 | 解鎖內容 |
|--------|----------|
| 80+ | 特殊對話、隱藏信息 |
| 70+ | 任務接受、物品贈送 |
| 50+ | 常規交易、日常對話 |
| 20+ | 有限互動 |
| 0-19 | 敵對、無法互動 |

### 好感度變化規則

| 行動 | 好感度變化 |
|------|-------------|
| 送禮物 +NPC 喜愛 | +5 ~ +20 |
| 完成 NPC 任務 | +10 ~ +30 |
| 對話互動 | +1 ~ +5 |
| 幫助 NPC (戰鬥/治療) | +10 ~ +25 |
| 攻击 NPC | -20 ~ -50 |
| 偷取 NPC 物品 | -30 ~ -60 |
| 冷酷對話 | -1 ~ -5 |

## 生活模擬

### 休息系統

玩家可以休息來：
- 回復 HP (治癒傷口)
- 回復 spirit (恢復靈力)
- 恢復 stamina (恢復體力)
- 觸發隨機事件 (夢境、NPC 造訪、危險)

休息時消耗 2 小時，可能觸發：
- NPC 造訪休息場所 (好感的 NPC 來探望)
- 夢境 (獲得 hint、記憶回憶)
- 危險事件 (野生怪物攻擊)
- 尋獲物品 (在休息場所發現東西)

### 時間系統

```
時間單位: 小時 (0-23)
遊戲天數: 第 X 天
季節: 春/夏/秋/冬

時間影響:
- NPC 的位置和活動
- 某些場景的光線/氛圍
- 特定事件的觸發條件
- 商店開放/關閉時間
```

### 非冒險活動

遊戲不只是冒險，還包括以下模擬元素：

| 活動 | 描述 | NPC 互動 |
|------|------|-----------|
| 閒逛 | 在場景中行走，探索 | 可能遇到 NPC |
| 購買 | 在商店買賣物品 | 商店 NPC 交易 |
| 休息 | 在住所休息 | 隨機事件 |
| 觀察 | 仔細觀察場景 | 可能發現隱藏內容 |
| 對話 | 與 NPC 深度互動 | 好感度變化 |
| 製作 | 在工作台合成物品 | 需要技能 |
| 交換 | 與 NPC 交換物品 | 雙方滿意 |

### 日程系統視角

從 NPC 視角，遊戲每天重複他們的作息循環：

```
一天循環:
起床 → 工作 → 午餐 → 下午活動 → 晚餐 → 休息 → 睡眠
06:00  10:00   12:00   14:00      18:00  20:00  22:00
```

玩家觀察並參與 NPC 的日常活動是模擬系統的核心。
