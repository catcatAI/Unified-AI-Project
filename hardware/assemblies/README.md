# assemblies/ — 組件區（產品級組合）

`done/`
= 本層完成的產品（規格+圖+仿真自洽，附 package_manifest 自含打包，元件卡複製自 components/done/）；`wip/`
= 概念/草稿級，**不打包、不宣稱完成**。邊界：edge_card（done，外購模組小卡）與 ai_compute_card（wip，自研矽大卡）是兄弟產品線，互不回答 pending_decision。規則見 ../README.md。

> **區性**：本工作區是**設計與設計驗證區**（規格/圖/仿真/審計文件），未進行任何實體開發（未下板、未打樣、未採購、未量測）；`done`
> = L0 設計文件完成，非實體完成（見 hardware/README.md 區性聲明）。
