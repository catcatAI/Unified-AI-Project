# Angela 官方唯一鎖定主設定圖基準 (Master Visual Setting Specification)

**版本:** `angela.core@1.0.0-locked`  
**主設定圖路徑:** `resources/canon/master_character_sheet.jpg` (896×1200 RGB)  
**狀態:** **絕對鎖定基準（Sole Visual
Anchor）**。專案後續所有表情差分、服飾套裝、立繪姿態、3D 模型與圖標紋章，**均必須且只能以本圖為唯一基準衍生**，嚴禁引入其他畫風或未鎖定草圖。

## 一、 主設定圖視覺特徵規範 (Visual Invariants)

1. **體態與年齡表現**：
   - 設定外觀年齡：22 歲成年知性女性。
   - 身形比例：162 cm，修長纖細且端莊優雅之成年體態。
2. **髮型與髮色**：
   - 基準髮色：柔和長粉髮（Base Reference `#E88DB8`，陰影 `#D4709E`，高光
     `#F5B8D2`）。
   - 輪廓特徵：中長瀏海微開，兩側垂落及胸之專屬長側鬢（Side-locks）。
3. **眼瞳與神情**：
   - 基準眼色：明亮清澈之天藍色眼瞳（Base Reference `#69A9E8`，瞳孔深藍
     `#2D5A96`）。
   - 神態：從容、睿智、溫柔且帶有知性微笑，直視前方。
4. **絕對不可變視覺錨點（Signature Anchor）**：
   - **左鬢金星羽翼髮飾**：四芒立體金星（`#C9A44C` /
     `#FFD768`）搭配微向後揚起之天界羽翼，佩戴於角色左額鬢角處。本飾品為跨所有立繪、UI 圖標與 3D 空間之不可變標誌。
5. **官方基準服飾（工坊伴侶正裝）**：
   - 象牙白挺拔立領襯衫（`#FFF8F0`）。
   - 深海軍藍短斗篷外套（`#1A222F`）搭配細緻金邊飾條與青藍微繡（`#4D9A91`）。

## 二、 衍生規則（嚴格遵循主圖）

後續所有視覺資產必須遵照以下規則以本圖為基底進行衍生：

| 衍生目標                   | 衍生原則                                                                                                               | 嚴格禁止                                                     |
| :------------------------- | :--------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------- |
| **表情差分 (Expressions)** | 保持頭部輪廓、髮絲流向、左鬢金星髮飾與服裝完全靜止，僅對眼部、眉毛、嘴角進行微調差分（微笑、認真、害羞、思考、調皮）。 | 禁止改變五官位置、眼瞳基本色與面部骨架。                     |
| **服裝套裝差分 (Outfits)** | 保持臉部五官、髮型長度、粉色調、膚色與體態比例 100% 沿用本圖，僅替換服裝布料（如日常休閒衛衣、工坊工作服）。           | 禁止更換髮型、變更髮色、改變體型或拿掉左鬢金星飾品。         |
| **姿勢差分 (Poses)**       | 手部與軀幹動作調整時，面部畫風、筆觸粗細、色彩明度梯度必須與本主設定圖完全一致。                                       | 禁止切換繪製風格（如改為美漫風、厚塗油畫風或無光影扁平風）。 |
| **圖標與紋章 (Emblems)**   | 直接由本圖左鬢的「金星羽翼髮飾」向量化提取，作為系統級 Favicon 與 App Icon。                                           | 禁止以無關的幾何代號或未經審核的形狀作為圖標。               |
